Opening a folder

File > Open Vault… (⌘O) and pick a folder of Markdown notes. Weaverlet reads and edits the files in place; nothing is imported or moved.

Where are my notes?

In the folder you opened, as plain files. If you set a folder sort, colors or bookmarks, Weaverlet keeps them in a .weaver folder inside it.

What does the account sync?

Only settings (appearance, fonts, editor options, shortcuts, file browser preferences). Notes stay on your Mac. You can use Weaverlet without an account.

Deleting your account

Settings > Vault & Account > Delete Account…. See the privacy policy.

폴더 열기

파일 > 볼트 열기…(⌘O)로 Markdown 노트 폴더를 고릅니다. 파일은 그 자리에서 읽고 고치며, 가져오거나 옮기지 않습니다.

노트는 어디에 있나요?

연 폴더 안에 평범한 파일로 있습니다. 폴더 정렬, 색, 북마크를 정하면 그 폴더 안 .weaver 폴더에 저장합니다.

계정으로 무엇이 동기화되나요?

설정(모양, 글꼴, 편집기 옵션, 단축키, 파일 탐색기 설정)만입니다. 노트는 Mac에 남습니다. 계정 없이도 쓸 수 있습니다.

계정 삭제

설정 > 볼트·계정 > 계정 삭제…. 개인정보처리방침을 참고하세요.
