MatchPage stats - Privacy Policy

Effective date: 2026-10-25

MatchPage stats is a private tool used only by the operator of the YouTube channel MatchPage to read that channel's own performance numbers. It is not offered to other users.

Data accessed

  • With the youtube.readonly scope: the channel's own videos' view counts, titles and publish times.
  • With the yt-analytics.readonly scope: the channel's own videos' average view percentage.

No other Google account data is requested. The tool cannot upload, edit or delete anything on YouTube.

How the data is used

The numbers are used only to build internal weekly reports for the channel operator (views 24 and 72 hours after publishing, retention, grouped by video format and team).

Storage and security

Data is stored only on the operator's own computer. OAuth credentials are kept in the macOS Keychain. Nothing is stored on any server run by this tool.

Sharing

The data is not sold, shared with or transferred to any third party, and is not used for advertising.

Google API Services User Data Policy

MatchPage stats' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Locally stored numbers can be deleted by the operator at any time.

MatchPage stats 개인정보처리방침

시행일: 2026-10-25

MatchPage stats는 YouTube 채널 MatchPage 운영자 본인만 쓰는 도구로, 그 채널 자신의 성과 숫자를 읽습니다. 다른 사용자에게 제공하지 않습니다.

읽는 정보

  • youtube.readonly: 채널 자신의 영상 조회수, 제목, 공개 시각
  • yt-analytics.readonly: 채널 자신의 영상 평균 시청 비율

그 밖의 Google 계정 정보는 요청하지 않습니다. YouTube에 무엇을 올리거나 고치거나 지울 수 없습니다.

쓰는 곳

채널 운영자용 내부 주간 보고(공개 24·72시간 조회수, 시청 지속률, 형식·팀별 묶음)에만 씁니다.

보관과 보안

정보는 운영자 본인 컴퓨터에만 저장합니다. 인증 정보는 macOS 키체인에 둡니다. 이 도구가 운영하는 서버에는 아무것도 저장하지 않습니다.

공유

정보를 판매하거나 제3자에게 제공·이전하지 않고, 광고에 쓰지 않습니다.

Google API 서비스 사용자 데이터 정책

Google API에서 받은 정보의 사용과 이전은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

접근 취소

myaccount.google.com/permissions에서 언제든 접근을 취소할 수 있습니다. 저장된 숫자는 운영자가 언제든 지울 수 있습니다.
